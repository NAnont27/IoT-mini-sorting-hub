# Mini Sorting Hub — แบบกลไกสายพานพร้อมชุดชั่ง

อัปเดต: **23 พฤศจิกายน 2026 (Asia/Bangkok)** · Decision **D022**

**สถานะ:** ผู้ใช้เลือกแนวทางตามภาพด้านล่างแล้ว เอกสารนี้เป็นแบบแนวคิดสำหรับทีมใช้วางแผนและทดลอง ยังไม่ใช่แบบผลิตที่ยืนยันขนาด แรง ระยะเดินทาง หรือความแม่นยำ และยังไม่ได้เปลี่ยน firmware/controller ให้ทำงานตามกลไกนี้

## 1. แบบที่เลือก

![สายพานพากล่องไปสามช่อง พร้อมชุดชั่ง](conveyor_with_scale_concept_v2.png)

- ใช้สายพานผิวกว้างพากล่องไปตามแนวยาว รับทีละกล่อง ฉลากหงายขึ้น
- ช่องรับคงที่สามช่องอยู่ด้านหน้าสายพาน: **A / B / HOLD**
- **MG996R** ขับเพลาสายพานโดยตรงในแนวแกนเดียวกัน ใช้การหมุนไป–กลับภายในช่วงมุมที่ทดลองแล้ว
- **MG90S** ทำหน้าที่ปัดกล่องลงช่อง และเคลื่อนตามไปกับกล่องบนชุดนำทางขนาดเล็กด้านหลังสายพาน
- **Load cell + HX711** รองชุดสายพานเพื่อชั่งเมื่อสายพานหยุด ช่องรับแยกจากชุดที่ชั่ง
- โครงหลักใช้ฟิวเจอร์บอร์ดเสริมความแข็ง ใช้ไม้เป็นแกน/ชิ้นเสริม และตั้งใจประกอบโครงโดยไม่ใช้น็อต

กล่องวางบนสายพานโดยตรง ไม่ใช่ถาดกล่องที่ถูกดึงให้เลื่อนบนแกนไม้ แกนไม้ด้านหลังภาพมีไว้ประคองชุดตัวปัดเท่านั้น

เพลาหมุนและส่วนรองสายพานที่หัว–ท้ายยังจำเป็นสำหรับให้สายพานวนกลับ โดยเก็บไว้ใต้ฝาครอบปลายตามภาพ ไม่ใช้ลูกกลิ้งไม้ก้อนใหญ่ที่ยื่นออกมาแบบภาพก่อนหน้า

**ขอบเขตการเลือก:** ยอมรับรูปแบบและการจัดวางนี้ ส่วนรายละเอียดข้อต่อเพลา การพาตัวปัดเคลื่อน จุดยึด Load cell และขนาดชิ้นส่วนยังต้องทดลอง ไม่ถือว่ารายละเอียดทุกจุดในภาพผ่านการออกแบบทางกลแล้ว

## 2. ส่วนประกอบและหน้าที่

| ส่วน | หน้าที่ | สถานะรายละเอียด |
|---|---|---|
| ผิวสายพานแบบยืดหยุ่น | รองกล่องและพาไปตามแนวยาว | ต้องเลือกวัสดุที่ยึดเกาะกล่องและต่อเป็นวงได้ ฟิวเจอร์บอร์ดใช้ทำโครง ไม่ใช้เป็นผิวสายพานวน |
| เพลาขับและเพลาปลายอีกด้าน | รองรับการวนกลับของสายพาน | ต้องกำหนดขนาด วิธีรองเพลา และการปรับความตึง |
| MG996R เดิม | หมุนเพลาขับสายพานไป–กลับ | ยังไม่พิสูจน์ว่าระยะและแรงเพียงพอกับสามช่อง |
| Horn และข้อต่อเพลา | ส่งการหมุนจาก Servo เข้าเพลาในแนวเดียวกัน | ต้องยึดให้ไม่ลื่นหรือโยก ไม่ใช้ก้านชักเยื้องแกนแทนข้อต่อหมุนตรง |
| MG90S เดิมและแผ่นปัดเบา | ปัดกล่องออกด้านหน้าเมื่อสายพานหยุด | ต้องทดลองแรง ระยะปัด และตำแหน่งเก็บแขน |
| ชุดนำทางตัวปัด | ให้ตัวปัดเคลื่อนตามแนวยาวโดยไม่เอียง | เสนอไม้กลมขนานกับปลอกหลอดแข็ง ไม่รองถาดกล่อง |
| Load cell แบบแท่งเดิม | รับแรงจากชุดสายพานและกล่อง | ต้องตรวจรุ่น พิกัดน้ำหนัก ขนาดแท่น และโมเมนต์ที่รองรับ |
| HX711 เดิม | อ่านสัญญาณ Load cell ส่งให้ ESP32 | ต่อวงจรเดิมได้ แต่ต้องสอบเทียบใหม่หลังเปลี่ยนฐาน |
| ฐานล่างคงที่ | รับ Load cell และวางช่องรับ | ต้องแข็งและไม่บิดเมื่อสายพานขยับ |
| ช่องรับ A/B/HOLD | รับกล่องที่ถูกปัด | อยู่ต่ำกว่าผิวสายพานและไม่สัมผัสชุดที่ชั่ง |

ฟิวเจอร์บอร์ดสองชั้น ค้ำสามเหลี่ยม เทปผ้า กาว และเคเบิลไทเป็นวิธีประกอบโครงที่เสนอ ต้องทดลองความแข็งจริง จุดยึดเพลาและ Load cell ต้องแน่นและทำซ้ำได้ การไม่ใช้น็อตยังเป็นข้อกำหนดที่ต้องหาวิธียึดให้ผ่าน ไม่ถือว่ากาวแทนได้ทุกจุดโดยอัตโนมัติ

สกรูสั้นล็อก horn ที่มากับ Servo แนะนำให้คงไว้ แยกจากน็อตประกอบโครงที่ผู้ใช้ต้องการหลีกเลี่ยง ไม่อัดกาวลงในแกน Servo

## 3. รูปแบบการทำงานที่ตั้งใจ

```text
เริ่มที่ตำแหน่งรับกล่อง สายพานหยุด แขนปัดเก็บ
  → วางกล่องทีละใบ
  → ตรวจการวาง / รอน้ำหนักนิ่ง / ตรวจขนาดที่จุดรับ
  → บันทึกน้ำหนักและถ่ายฉลาก
  → OCR → AI → ตรวจทะเบียนและกฎ → ได้ A / B / HOLD
  → สายพานพากล่องและชุดปัดไปตำแหน่งที่เลือก
  → หยุดและรอการเคลื่อนนิ่ง
  → MG90S ปัดกล่องลงช่อง → เก็บแขนปัด
  → ตรวจว่ากล่องออกจากชุดสายพานตามวิธีที่จะทดลองยืนยัน
  → สายพานหมุนกลับจุดรับพร้อมชุดปัด
  → ตรวจพร้อมรับกล่องใหม่ → บันทึกผล
```

นี่เป็น **ลำดับออกแบบสำหรับกลไกใหม่** ยังไม่ใช่พฤติกรรมของโปรแกรมปัจจุบัน

- ช่วงแรกยังเลือก A/B/HOLD บนเว็บเพื่อทดสอบได้ ก่อนเสียบผลจากทีม AI
- อ่านฉลากไม่ได้ ใช้การถ่ายซ้ำจำกัดจำนวนก่อน HOLD ตามขอบเขตเดิม
- AI/API ล่ม ให้พักที่จุดรับและรอลองใหม่ ไม่ใช้ HOLD แทนเหตุระบบล่ม
- A/B แบ่งกลุ่มชั้นตามทะเบียน ส่วน HOLD คือรอตรวจ ไม่ได้ปิดเคสให้เจ้าหน้าที่อัตโนมัติ
- รับชิ้นใหม่หลังสายพานกลับจุดรับ แขนปัดเก็บ และพื้นที่ทำงานว่างแล้ว

## 4. ระยะที่ MG996R หมุน 180° พาไปได้

การมีสามมุมคำสั่งไม่ได้ทำให้ระยะสายพานเพียงพอเอง ต้องคำนวณจากขนาดเพลาหรือผิวขับที่สัมผัสสายพานจริง

ถ้าขับตรง 1:1 และไม่มีการลื่น:

```text
s = π × D × Δθ / 360

s  = ระยะที่สายพานเคลื่อน
D  = เส้นผ่านศูนย์กลางผิวขับที่สัมผัสสายพาน
Δθ = มุมหมุนจริงของเพลาขับ หน่วยองศา
```

| ตัวอย่าง D | ระยะเมื่อหมุนจริง 180° |
|---|---:|
| 4 ซม. | ประมาณ 6.3 ซม. |
| 8 ซม. | ประมาณ 12.6 ซม. |
| 12 ซม. | ประมาณ 18.8 ซม. |

ตัวเลขเป็น **การคำนวณตัวอย่าง ไม่ใช่ขนาดที่เลือกซื้อหรือรองรับแล้ว** ถ้าต้องเลื่อน 20 ซม. การขับตรงภายใน 180° ต้องมี D ประมาณ 12.7 ซม. จึงยังมีข้อจำกัดระหว่างปลายสายพานขนาดเล็กกับระยะเดินทางยาว

ต้องวัดระยะจากจุดรับกล่องถึงช่องไกลสุด รวมตำแหน่งตัวปัดและระยะเผื่อจริง ไม่วัดแค่ช่วงกลาง A ถึง HOLD หากจุดรับอยู่ก่อน A และต้องใช้ช่วงมุมที่ Servo ไม่ฝืนปลาย

ผิวขับใหญ่ขึ้นให้ระยะมากขึ้น แต่แรงดึงที่ได้จากแรงบิดเท่าเดิมลดลง หากขับตรงไม่พอ ต้องนำผลทดลองมาคุยเรื่องอัตราทด มิติ หรือชนิดมอเตอร์อีกครั้ง **ยังไม่อนุมัติเปลี่ยนมอเตอร์หรือเพิ่มชุดเกียร์ในเอกสารนี้**

## 5. การพาตัวปัดเคลื่อนตาม

ตัวปัดต้องอยู่หลังกล่องในตำแหน่งที่ปัดออกด้านหน้าได้ โดยเก็บแขนให้พ้นกล่องระหว่างวิ่ง

ข้อเสนอสำหรับทดลองคือจับชุดตัวปัดกับขอบสายพานช่วงบน แล้วประคองชุดตัวปัดด้วยแกนไม้/ปลอกหลอด เพื่อให้สายพานพาทั้งกล่องและตัวปัดไปพร้อมกันโดยไม่เพิ่มมอเตอร์เลื่อนอีกตัว

ยังต้องพิสูจน์ว่า:

1. จุดจับไม่ทำให้สายพานเบี้ยว ลื่น หรือเสียดสีกับโครง
2. จุดจับอยู่บนช่วงสายพานตรงตลอดการไป–กลับ ไม่เข้าโค้งหัว–ท้าย
3. ปลอกเลื่อนไม่ติดและแรงต้านไม่มากจน MG996R ขับไม่ไหว
4. กล่องไม่ลื่นจนระยะห่างจากตัวปัดเปลี่ยนมากเกินไป
5. สายไฟ MG90S มีระยะหย่อนและไม่ดึงชุดชั่งหรือเข้าจุดหมุน
6. MG90S ปัดกล่องตัวอย่างได้โดยไม่ค้าง และกลับตำแหน่งเก็บได้

ภาพแสดงตำแหน่งชุดตัวปัด แต่ไม่ได้ให้รายละเอียดข้อต่อที่ทำเสร็จแล้ว หากวิธีจับขอบสายพานไม่ผ่าน ต้องทบทวนวิธีขับร่วมก่อน ไม่ถือว่ามีมอเตอร์แกนที่สามอยู่ในแผนแล้ว

## 6. การติดตั้ง Load cell และ HX711

### 6.1 ขอบเขตที่ชั่ง

ข้อเสนอในภาพคือให้ **โครงสายพานส่วนบนทั้งชุด** อยู่บน Load cell รวม Servo และชุดตัวปัดที่ติดอยู่กับโครงนั้น ช่องรับทั้งสามอยู่บนฐานภายนอกแยกออกไป

```text
กล่อง + สายพาน + โครงส่วนบน + มอเตอร์/ชุดตัวปัด
                      ↓
         ปลายรับแรงของ Load cell
                      ↓
          ส่วนวัดแรงตรงกลางแท่ง
                      ↓
          ปลายที่ยึดกับฐานล่าง
                      ↓
                  ฐานคงที่
```

พิกัดต้องครอบคลุมน้ำหนักโครงและกล่องรวมกัน รวมทั้งเงื่อนไขขนาดแท่น/ตำแหน่งลงแรงตามสเปกเซนเซอร์ การ tare หักน้ำหนักโครงออกจากค่าที่อ่าน **ไม่ได้เพิ่มพิกัดรับน้ำหนักของ Load cell**

### 6.2 วิธีรองแรง

- ปลายหนึ่งของ Load cell ยึดกับฐานล่าง อีกปลายรับโครงสายพานผ่านชิ้นรองด้านบน
- เว้นช่วงกลางแท่งให้ยืดตัวได้ และเว้นช่องว่างไม่ให้โครงบนแตะฐานล่าง
- ขาโครง ฝาครอบ จุดยึด Servo ช่องรับ และสายไฟต้องไม่เป็นทางรับแรงข้าม Load cell
- จุดยึดแบบหนีบไม้/เคเบิลไทในภาพเป็นแนวคิด ต้องทดสอบความแน่น การคืบ และการกลับศูนย์ ไม่ใช่แบบยึดที่ยืนยันความแม่นยำแล้ว
- ทำโครงส่วนบนให้แข็งพอ ไม่ปล่อยให้คานฟิวเจอร์บอร์ดยาวบิดหรือแตะชิ้นส่วนอื่นเมื่อกล่องย้ายตำแหน่ง

### 6.3 การอ่านและสอบเทียบ

1. ทำจุดรับกล่องและตำแหน่งพักแขนปัดให้ซ้ำเดิม
2. ตรวจว่าไม่มีของค้างและโครงไม่แตะฐาน แล้ว tare น้ำหนักโครงที่ตำแหน่งเริ่มต้น
3. สอบเทียบด้วยน้ำหนักอ้างอิงที่ชั่งจริงตามคู่มือ HX711 เดิม
4. ทดสอบวางน้ำหนักเดิมบริเวณจุดรับและตำแหน่ง A/B/HOLD เมื่อระบบหยุด ตรวจทั้งค่าที่อ่านและการกลับศูนย์
5. ใช้น้ำหนักตอนหยุดนิ่งเป็นค่าน้ำหนักงาน ไม่ใช้ค่าช่วงมอเตอร์กำลังเร่ง/ปัดเป็นน้ำหนักกล่อง
6. หลังกล่องออกและแขนปัดเก็บ ตรวจค่ากลับใกล้ baseline ตามตำแหน่งนั้นก่อนคืนต้นทาง ห้าม tare ทับกล่องค้างหรือใช้ tare กลบค่าผิดปกติ

ค่าเกณฑ์นิ่ง ค่าคลาดเคลื่อนที่รับได้ และขอบเขตน้ำหนักยังต้องกำหนดจากผลทดลอง ไม่ใส่ตัวเลขสมมติเพื่อข้าม readiness

## 7. เซนเซอร์และระบบเดิมที่ต้องเชื่อมต่อ

ยังคงเซนเซอร์ห้าชนิดและสถาปัตยกรรม ESP32 → MQTT → Backend บน Pi → Database/Dashboard ตามโปรเจกต์เดิม

| เซนเซอร์ | บทบาทในแบบสายพาน | สิ่งที่ต้องปรับ/ตรวจ |
|---|---|---|
| Load cell + HX711 | ชั่งและตรวจพื้นที่ว่าง | สอบเทียบใหม่หลังประกอบโครง; ตรวจ baseline แต่ละตำแหน่ง |
| E18 ตัวเดียว | ตรวจกล่องที่จุดรับ | กล่องวิ่งพ้น E18 เป็นเหตุปกติ ห้ามใช้กฎเดิมตัดสินว่าหายก่อนปัด |
| VL53L0X | ตรวจความสูงที่จุดรับ | วัดเมื่อกล่องยังอยู่ใต้เซนเซอร์ ไม่ใช้การวิ่งออกจากจุดวัดเป็น fault โดยอัตโนมัติ |
| AS5600 | เสนอวัดมุมเพลาขับด้วยแม่เหล็ก | ต้องเลือกจุดติดตั้ง/อ้างอิงใหม่ มุมเพลาไม่ยืนยันตำแหน่งกล่องหากสายพานหรือกล่องลื่น |
| BH1750 | ตรวจแสงบริเวณอ่านฉลาก | อยู่กับจุดรับกล่องและกล้อง ตรวจภาพจริงร่วมด้วย |

กล้องอ่านฉลากที่จุดรับขณะสายพานหยุด ยังใช้ Pi Camera Module 3 และโมดูล AI ของทีมเดิม ไม่สร้าง pipeline ใหม่ในงานเอกสารนี้

### ผลกระทบต่อโค้ด

Firmware ปัจจุบันยังให้ GPIO6 เป็น Servo ประตู และ GPIO7 เป็น Servo ราง ส่วน controller ยังใช้ลำดับตั้งราง → เปิดประตู → ตรวจ IR ถาดว่าง แบบ BENCH เดิม **ยังไม่ใช่โค้ดควบคุมสายพานตามเอกสารนี้**

ก่อนนำไปใช้กับกลไกที่ประกอบแล้ว ต้องปรับบทบาท Servo เป็นปัด/ขับสายพาน ลำดับเดินทาง–หยุด–ปัด–คืนต้นทาง และเงื่อนไขเซนเซอร์ตามช่วงงาน พร้อมตรวจ feedback และ timeout โดยไม่ปิด interlock เพื่อให้ผ่าน

ยังไม่มีเซนเซอร์ปลายทางแต่ละช่อง: การที่น้ำหนักกลับใกล้ศูนย์บอกได้เพียงของออกจากชุดที่ชั่ง ไม่ยืนยันว่าลงช่องถูก ต้องเก็บ `destination_sensed=false` และระบุข้อจำกัดนี้ในรายงาน ไม่อ้างว่ารุ่นนี้ตรวจคัดผิดช่องได้

## 8. ลำดับเริ่มประกอบและตรวจ

| ขั้น | สิ่งที่ทำ | หลักฐานที่ต้องได้ก่อนทำต่อ |
|---|---|---|
| 1 | วัดกล่องจริงสามขนาดและวางตำแหน่งสามช่อง | ขนาด น้ำหนัก และระยะจากจุดรับถึงช่องไกลสุด |
| 2 | คำนวณขนาดผิวขับ/ช่วงมุมและลองหมุนด้วยมือ | ระยะจริงเพียงพอ สายพานไม่หลุดหรือเบี้ยว |
| 3 | ทดลอง MG996R ขับสายพานเปล่าแล้วค่อยเพิ่มกล่อง | เดินทางซ้ำตำแหน่งได้ ไม่ฝืน และไฟเลี้ยงไม่ทำให้บอร์ดรีสตาร์ต |
| 4 | ทำชุดปัดเคลื่อนตามและลองครบสามช่อง | ตัวปัดตามทัน เก็บแขนได้ กล่องตกลงช่องโดยไม่มีขอบขวาง |
| 5 | ชั่งน้ำหนักชุดโครงและตรวจสเปก Load cell | พิกัด/ขนาดแท่นเหมาะสมและมีจุดยึดที่ทำซ้ำได้ |
| 6 | ติดตั้ง Load cell/HX711 และสอบเทียบ | กลับศูนย์และอ่านน้ำหนักอ้างอิงได้ตามเกณฑ์ที่ทีมกำหนด |
| 7 | กำหนดตำแหน่ง E18/ToF/AS5600/กล้อง | แยกเงื่อนไขจุดรับกับช่วงเคลื่อนที่ได้ชัด |
| 8 | ปรับ firmware/controller แล้วทดสอบครบ flow | ทดสอบปกติและ fault จริง ไม่มีการรายงานสำเร็จจาก ACK อย่างเดียว |

จ่าย Servo จาก Adapter 5V 5A แยกตามวงจรเดิม ต่อ GND ร่วมกับ ESP32 ไม่ส่งกำลังมอเตอร์ผ่านขาบอร์ด/เบรดบอร์ด และไม่ผูกขั้วบวกของแหล่งจ่ายต่างตัวเข้าด้วยกัน

## 9. รายการที่ยังต้องได้ข้อมูล

- ความกว้างสายพาน ความยาวใช้งาน และระยะจุดรับ/A/B/HOLD
- รุ่น/พิกัด/ขนาดแท่นที่ Load cell เดิมรองรับ และน้ำหนักโครงทั้งชุด
- วัสดุสายพาน วิธีต่อวง ความตึง ขนาดผิวขับ ข้อต่อ horn–เพลา และวิธีรองเพลา
- ช่วงมุม MG996R ที่ใช้งานจริงได้โดยไม่ฝืน และแรงที่เหลือเมื่อมีกล่อง/ชุดปัด
- วิธีพาตัวปัดเคลื่อนตามและระยะปัดที่ผ่านการทดลอง
- วิธีติดตั้งเซนเซอร์และเกณฑ์จบงาน/คืนต้นทางของ controller ใหม่

ไม่มีการล็อกขนาด 60×55×65 ซม. จากภาพเก่า หรือมุม 60/90/120° ของรางเดิมให้เป็นขนาด/มุมสายพานใหม่
