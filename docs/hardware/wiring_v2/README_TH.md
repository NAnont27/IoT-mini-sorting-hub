## วงจร IR หนึ่งช่อง

```text
+5V ── R1 1kΩ ──● A ── R2 10kΩ ──● B ── GPIO
                 │                  │
             ดำ OUT E18          R3 15kΩ
                                    │
                                   GND
```

- น้ำตาล E18 ไป +5V; น้ำเงิน E18 ไป GND ร่วม ESP32
- GPIO ต่อจุด B เท่านั้น ไม่ใช่จุด A และไม่ต่อสายดำตรงข้าม R2
- ทำซ้ำ 4 ชุดไป GPIO11/12/13/14 ไม่รวม OUT หรือจุด A/B ข้ามช่อง
- ใช้ไฟ regulated 5V ตามฉลาก ไม่ใช้กับเซนเซอร์ 12/24V
- IR ใช้ `INPUT` เพราะมี R ภายนอกครบแล้ว ปุ่ม GPIO10 ยังคง `INPUT_PULLUP`
- ก่อนต่อ GPIO ให้ใช้มิเตอร์วัดจุด B เทียบ GND ขณะเซนเซอร์มีไฟและบัง/ไม่บัง ขณะ HIGH คำนวณได้ประมาณ 2.885–3.0V; LOW ควรต่ำกว่า 0.8V และต้องไม่เกิน 3.3V
- ค่าจริงขึ้นกับแหล่งจ่าย ความคลาด R และเอาต์พุตของเซนเซอร์ ต้องวัด ไม่ถือว่ารูปหรือ unit test เป็นผลทดสอบฮาร์ดแวร์
- เปิด ESP32 ก่อน Adapter เซนเซอร์/Servo และปิด Adapter ก่อนถอด USB ESP32

## ของที่ใช้

| ตัวต้านทาน | จำนวน |
|---|---:|
| 1kΩ | 4 |
| 10kΩ | 4 |
| 15kΩ | 4 |
| 330Ω (LED สถานะ) | 3 |
| รวม | 15 |

ใช้ขนาด 1/4W; ถ้ามีเลือก 1% เพื่อความสม่ำเสมอ ไม่มี PC817 และไม่มี R เพิ่มที่ Servo

## ไฟและเลขขา

- Pi ใช้แหล่งจ่ายของ Pi, ESP32 ใช้ USB, Servo/IR ใช้ Adapter 5V5A
- GND ต่อร่วมตามแผน แต่ไม่ผูก +5V ของคนละแหล่ง และไม่ผูก 3V3 ของ Pi กับ ESP32
- ขาฝั่ง ESP32 ใช้ GPIO number ฝั่ง Pi ใช้ physical pin number
- GPIO6 ประตู / GPIO7 ราง ต้องแยกกัน ถอดสายพ่วงตรวจพัลส์จากการทดสอบเก่าออก
- Pi ขา 1→VCC สองเซนเซอร์, 6→GND, 3→SDA, 5→SCL; BH1750 ADDR→GND
- เส้นตัดกันเชื่อมต่อเมื่อมีจุดวงกลม ชื่อ NET เดียวกันภายในภาพเดียวกันหมายถึงจุดที่ต่อถึงกัน
- Camera Module3 ใช้ CSI 15→22 pin แยกสำหรับ Pi5 ไม่ต่อเข้า GPIO/I2C และยังไม่ใช้ในโหมดเลือกช่องบนเว็บ
