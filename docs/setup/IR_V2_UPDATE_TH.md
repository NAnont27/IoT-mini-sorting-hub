# ใช้ชุด v2 — ตัวต้านทานแทน PC817

15 พฤศจิกายน 2026

## เปลี่ยนอะไร

- โค้ด IR เดี่ยว/สี่ตัว/โปรแกรมรวม ตั้ง GPIO11–14 เป็น INPUT
- ปุ่มพัก GPIO10 ยังคง INPUT_PULLUP
- วงจร IR แต่ละช่องใช้ R1=1kΩ pull-up จาก +5V มาที่ OUT, R2=10kΩ จาก OUT ไป GPIO, R3=15kΩ จาก GPIO ลง GND
- LOW=DETECTED / HIGH=CLEAR และ mapping GPIO11=tray_exit, 12=A, 13=B, 14=HOLD ไม่เปลี่ยน
- ใช้ R1k×4, R10k×4, R15k×4, R330×3 สำหรับ LED รวม 15 ตัว ไม่ใช้ PC817
- ไม่มีการเปลี่ยนขา/โค้ดของ Pi, Servo, Load cell, ToF หรือกฎเลือกช่อง

## ไฟล์ที่ควรเริ่มอ่าน

1. ภาพและคำอธิบาย `docs/hardware/wiring_v2/README_TH.md`
2. ทดสอบ IR สี่ตัว `firmware/bench/07c_e18_four_live/07c_e18_four_live.ino`
3. โปรแกรมรวม ESP32 `firmware/esp32/hub_node/hub_node.ino`
4. คำสั่งติดตั้ง/อัปเดต Pi `docs/setup/BENCH_SETUP_TH.md`

## ทำก่อนรัน

1. ปิดไฟทุกแหล่ง แล้วต่อวงจร R ให้ครบแยกแต่ละช่อง ตรวจจุด B ที่เข้า GPIO ไม่ให้ต่อผิดเป็นจุด A (สายดำ)
2. ก่อนต่อ GPIO ใช้มิเตอร์วัดจุด B ทั้งตอนบัง/ไม่บังตามคู่มือ
3. ใช้โค้ดทดสอบ IR สี่ตัวก่อนรวม บังตัวใดต้องเปลี่ยนเฉพาะช่องนั้น
4. Upload โปรแกรมรวม v2 ไป ESP32 ใหม่ด้วย ถ้าเปลี่ยนแค่ไฟล์บน Pi แต่ไม่ได้ Upload บอร์ดจะยังรันโค้ดเดิม
5. ทดสอบข้อมูลบนเว็บก่อนกดเริ่มงานจริง ค่า IR ทั้งสี่ต้อง clear เมื่อทางว่าง

ชุด ZIP ไม่มี .env, config.json, secrets.h หรือฐานข้อมูลของผู้ใช้ ไม่รวม API key/รหัสผ่านจริง

สถานะ: ตรวจซอฟต์แวร์/คำนวณ 23 กรณีผ่าน แต่ยังไม่ได้ compile Arduino หรือทดสอบวงจร R กับอุปกรณ์จริง ต้องยืนยันแรงดันและการทำงานก่อนรวมระบบ
